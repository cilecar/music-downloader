# Music Sorter

Демон на Python. Следит за папкой-«входящими» и раскладывает скачанную музыку по библиотеке
в структуру `Исполнитель/Альбом/`, ориентируясь на теги.

## Возможности

- Следит за папкой через `watchdog` и обрабатывает файлы пачками: ждёт, пока докачается весь альбом
- Читает теги через `mutagen` и повторяет попытку, если файл ещё пишется
- Если пришёл один трек, кладёт его в папку `синглы`
- **Сессия исполнителя:** можно задать исполнителя вручную, и все входящие файлы пойдут к нему,
  какие бы ни были теги
- Поддерживает `.flac`, `.mp3`, `.m4a`, `.ogg`, `.opus`, `.wav`, `.aac`

## Установка

```sh
pip install watchdog mutagen
```

## Использование

```sh
python3 sorter.py              # запустить демон
python3 sorter.py set          # спросить текущего исполнителя
python3 sorter.py set PHARAOH  # задать исполнителя сразу
python3 sorter.py clear        # сбросить сессию (вернуться к тегам)
python3 sorter.py status       # показать текущую сессию
```

### Настройка

| Переменная    | По умолчанию                  | Что это               |
|---------------|-------------------------------|-----------------------|
| `MUSIC_INBOX` | `~/Музыка/inbox`              | Папка входящих файлов |
| `MUSIC_ROOT`  | `~/Музыка/nicotine/spotify`   | Корень библиотеки     |

### Как systemd-сервис (пользовательский)

Поправь путь в `ExecStart` в `music-sorter.service`, затем:

```sh
cp music-sorter.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now music-sorter
```
